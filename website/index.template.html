A FEW THINGS TO KNOW

开始之前，
你可能想知道。

支持哪些设备？+

支持 Android 7.0 及以上的 ARM64 设备。它是直接安装的 APK，终端和部分工具环境会在首次使用时准备。构建项目可能需要额外存储空间和网络。

Agent 是否需要自己配置模型？+

需要。选择 Pi、Codex 或 Gemini，按引擎要求填写服务地址、模型与 API Key。图片模型还需要支持图片输入，并有可用额度。Aster 不附带模型额度。

桌面操作需要哪些权限？+

需要先启动 Shizuku 服务，再在 Aster 的“设备权限”入口完成授权。执行模式下确认操作后，Agent 才能使用桌面工具。截图识图会在确认后发送给配置的模型。

网页和桌面工具有哪些边界？+

网页工具目前覆盖页面顶层元素的快照、点击与填写；跨域框架和画布内容需要进一步适配。桌面文字输入目前支持可打印 ASCII，网页填表支持 Unicode。真实设备交互仍待验收。

已有版本应该怎么升级？+

下载新 APK 直接覆盖安装。为保留项目、会话与设置，请不要先卸载或清除应用数据。若系统提示签名不一致，请先备份数据并检查安装来源。

在哪里获取源码和许可说明？+

下载区提供与普通版对应的源码和 SHA-256。项目包含不同开源许可的组件，轻舟为 AGPL-3.0、Operit 参考源码为 LGPL-3.0；详细来源和许可随源码附带。查看组件说明 ↗
