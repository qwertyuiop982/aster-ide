客户端源码

Aster 的账户版与原版均提供对应客户端源码。账户功能本身不改变继承的开源许可；两个 APK 分别对应各自的源码，不以另一份 APK 的源码替代。

账户版对应源码 ↗原版对应源码 ↗公开 GitHub 仓库 ↗

源码包包含保留的上游源文件、构建脚本、锁文件和许可证。服务端私有配置、上游 API Key、账户登录令牌和 Android 签名私钥不属于源码分发内容。

构建与版本对应

公开仓库提供 Android 工程、Gradle 配置、Agent 源码和原生构建配方。构建环境和要求见 DEVELOPMENT.md，账户版构建范围见 ACCOUNT-BUILD.md。请使用自己的签名密钥。

账户版预览从既有原生构建输出和保留的 UI bundle 组装；新机器需先按文档准备原生依赖。源码归档完整性已检查，尚未在全新机器上完成从源码归档开始的完整重建。

Release 校验文件记录每个 APK 与对应源码包的 SHA-256。验证记录说明签名、资源对应、离线和在线检查的具体范围，不把未执行的设备验证列为成功。

SHA-256 校验文件 ↗账户版验证记录 ↗原版验证记录 ↗

再分发

再分发时保留原版权、许可和组件来源，并履行适用许可要求的对应源码提供义务。账户版客户端不能因为同时提供另一个开源 APK 而省略自身的源码义务。
