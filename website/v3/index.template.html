完整使用指南 ↗
账户版与原版有什么区别？+

两者均包含完整 IDE。账户版预览新增 Aster 登录、积分与 Pi 账户模型；原版保留自定义模型流程。两版均提供相应客户端源码，账户版仍是测试构建。

64 次工具调用，会每次都用满吗？+

不会。64 是每次用户任务的上限，批量调用共享同一额度。任务完成时提前结束；新任务重新计算。实际模型请求可能包含有次数限制的格式恢复，所有正式回复按实际 token 计费。

我已有自己的模型和 API Key，可以继续用吗？+

可以。Pi 保留自定义 API；Codex 和 Gemini 继续使用自定义模型，不接入账户 free 服务。账户模型的上游由服务端管理。

两种版本可以并存吗？+

账户版与原版使用不同应用包，可以并存，项目和会话不会自动迁移。同一版本线升级建议先备份，再尝试覆盖安装。账户版更新后完全退出并重启内置环境，让新版工具循环生效。若系统提示签名冲突，请核对安装来源。

这些功能都经过实机验证了吗？+

最新账户版已通过 APK 构建、签名、包内凭据检查、16 项离线测试，以及公开网关与实际 Pi 循环的三文件连续读取测试。新版 APK 的 Android 安装与 IDE 设备操作尚待验收。查看完整验证记录。

源码、许可证与数据说明在哪里？+

下载区与 GitHub Release 提供对应源码和校验文件。客户端沿用 GPL 等组件许可，详细来源见源码与许可。账户与模型请求的数据处理见数据说明。
