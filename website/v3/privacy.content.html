浏览官网

官网是静态页面。工作台预览、引擎切换和积分估算在浏览器本地运行；服务状态区域只读取公开健康接口，不发起模型对话或账户登录。

访问网站时，服务器可能记录基础访问日志，例如请求路径、来源 IP、浏览器信息与时间，用于运行维护。下载链接经 gh-proxy.org 访问 GitHub Release，相关请求也会经过这两个服务；如不需要加速，可直接打开 GitHub Release。

账户登录与用量

账户版通过 GitHub 授权在 Aster 服务端建立账户和登录会话。服务端保存用于账户识别、余额、签到和用量结算的数据。积分记录与登录状态由服务端维护。

请从应用内发起登录，不在普通网页或公开 Issue 中粘贴登录令牌。退出登录使用应用内账户页入口。当前邮箱登录尚未开放。

模型与项目内容

使用账户模型时，对话、所选项目上下文和工具结果会发送到 Aster 网关，再转发给配置的模型提供方完成请求。为记录用量和支持同一请求的缓存重放，服务端会保存该请求的结算及最终回复。Go 的推理文本不返回客户端，也不作为公开最终回复缓存。

自定义 API 的请求发往你配置的服务提供方。使用前请了解其数据处理方式。不要将不应外传的项目文件、个人信息或密钥加入模型上下文。

网页、MCP 或设备工具会处理相应页面、工具输入和结果。截图识图在应用确认后会把截图上传给配置的图片模型。

你的选择

可以使用自定义 API、选择项目上下文、关闭账户模型，或退出账户。文件修改与需要批准的操作仍在应用内确认。公开 GitHub 仓库只存放客户端代码、网站和发布说明，不存放服务端凭据或用户登录令牌。

如需报告问题，请通过 GitHub Issues提供不含凭据的错误代码和复现步骤。涉及个人数据时，不要把原始日志直接发布到公开页面。
