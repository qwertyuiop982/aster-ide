01 / 安装与升级

Aster 面向 ARM64 Android 设备，包含代码编辑器、终端和 Agent。下载前请确认设备架构与系统版本；首次准备运行环境需要联网和足够的存储空间。

  1. 从官网下载区或 GitHub Release选择账户版预览或原版。
  2. 按系统提示允许浏览器或文件管理器安装 APK，然后打开 Aster。
  3. 账户版（dev.aster.account）与原版（dev.aster.ide）是两个独立应用包，可以并存，数据不会自动迁移。同一版本线升级先备份，再尝试覆盖安装；不要先卸载或清除应用数据。
  4. 升级到 free64 预览后，完全退出并重新启动 Aster 和内置环境，使新的工具循环生效。

账户版预览是测试构建。已完成构建、签名和协议验证，新版 APK 的 Android 安装及 IDE 设备操作仍待验收。若系统提示签名冲突，请核对安装来源并先备份数据。

02 / 选择你的工作方式

IDE 模式

导入或创建项目，编辑文件、搜索代码，按需要准备语言服务。终端与构建使用内置环境，项目文件与构建依赖需要存储空间。

独立 Agent 模式

围绕一个项目进行问答、规划和执行。可以提供显式文件上下文，保留会话并继续任务。通过模式切换入口返回首页，可重新选择 IDE 或 Agent。

问答与规划以读取和分析为主；执行模式可以准备文件修改、请求命令及其他工具操作。修改需查看预览，命令沿用应用内批准流程。

03 / 准备运行环境

按应用提示初始化内置 Termux 环境，然后安装所需语言服务与构建工具。新版 Agent 安装流程会先刷新和升级软件包，更新 libc++，再安装 Node LTS 并实际检查可执行性。

Pi 使用 Node.js 22.19 或以上版本。若旧版本出现 Node 无法启动或缺少 C++ 运行库符号，请在新版中重新运行 Agent 环境安装，再重启内置环境。

不要在项目尚未准备依赖时把构建失败当成 Agent 连接失败。终端输出、模型连接、工具结果和编译结果需要分别查看。

04 / 登录与积分

  1. 在首页或设置中打开“账户 / 登录”。
  2. 选择 GitHub 登录，在浏览器中完成授权并返回应用。
  3. 查看账户余额，在应用内完成每日签到。
  4. 选择 Pi 引擎，将模型来源设为“账户模型”，再选择 free 或 free go。

新账户奖励 1,000 积分；按北京时间每日签到一次，奖励 100 积分，以服务端账户记录为准。登录、余额和用量由服务端维护。当前邮箱登录尚未开放。

GitHub 登录应从应用发起。无需在官网手动填写回调地址或粘贴登录令牌；应用会处理自己的登录校验信息。

05 / 账户模型与自定义模型

引擎模型来源使用方式
Pi账户模型 / 自定义 API可选择 Aster-free、Aster-free go，或填写自己的模型配置。
Codex自定义 API填写服务地址、模型名称与 API Key，不使用账户 free 服务。
Gemini自定义 API按引擎要求配置 Gemini API 或兼容的 OpenAI 接口，不使用账户 free 服务。

账户模型的价格

Aster-free：每 1,000 个实际输入与输出 token 扣除 1 积分，固定无思考。Aster-free go：每 1,000 token 扣除 50 积分，固定最低推理强度，只显示最终内容；输出用量包含推理 token，不重复相加。两档的输入与输出总预算上限为 128,000 token。

服务端的短输入用量预检属于服务成本，不扣用户积分。正式模型回复按实际用量结算。相同请求的缓存重放不会重复扣费。客户端的格式恢复属于新的正式模型回复，也按实际用量结算。

账户模型的真实上游、密钥与固定模型规则由服务端维护，客户端无需填写。自定义 API 的用量与费用由你选择的服务提供方处理。

06 / 连续工具调用

Pi 账户模式每轮用户任务最多执行 64 次工具调用。多项批量调用共享该额度，完成任务时可以提前结束；发送新的用户任务时重新计算。

工具执行后，结果会回传模型以继续原任务。若模型把工具参数写成普通文字，新版会要求它恢复正确的工具 JSON，最多在初次回复后恢复两次。文字描述本身不会执行工具。连续格式异常会明确报错。

已验证的公开网关测试中，两档都使用实际 Pi 循环连续读取了三个相互链接的临时文件，随后调用 finish。64 次上限与批量调用边界通过离线回归测试。该验证在 Linux 临时项目上进行，不代表 Android IDE 的所有工具已完成设备验收。

07 / 网页、设备与 MCP 工具

Shizuku 设备工具

需要先安装、启动独立的 Shizuku 应用，再在 Aster 中完成授权。设备读取、截屏和坐标操作取决于权限与设备状态。截图识图会在确认后发送给已配置的图片模型，需要支持图片输入并有可用额度。设备能力仍需实机验收。

轻舟网页工具

可以打开网页、读取页面顶层元素并点击、填写。跨域 iframe、画布与复杂页面仍有适配限制，页面变化后应重新获取信息。

MCP

支持 HTTP 与 stdio 工具传输。在项目的 .aster/mcp.json 中配置工具服务器，再在引擎设置中启用。连接与调用沿用应用内批准流程。项目 Skill 可按引擎选择启用。

08 / 常见问题排查

账户模型暂不可用

刷新账户服务状态，检查网络、登录与余额。服务端返回的错误代码会区分未配置、用量不匹配和上游暂不可用，错误信息中请勿附带个人令牌。

工具只执行一次

确认安装的是 free64 新版账户 APK，并完全退出后重启内置环境。新的 64 次上限与格式恢复均需要更新客户端；只切换服务端模型不会更新旧 APK 中的循环逻辑。

修改没有出现在原文件中

先查看待预览修改，确认应用修改的操作是否已经完成。工具生成修改建议与实际写入用户项目是不同步骤。

需要源码或校验值

每个 APK 旁边均提供对应的源码下载和 SHA-256。可以在电脑或支持校验的文件工具中核对，详情见源码与许可。
