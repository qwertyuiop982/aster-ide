1.0.4 快速开始

首页提供 1.0.4-agent-tools 预览 APK。安装前建议备份项目，进入 Aster 后先准备运行环境，再配置模型和工具。以下介绍新能力，后文保留原有安装、账户与项目指南。

子代理模型

在 Agent 模型设置或 IDE 的 Agent 设置中填写“子代理候选模型”，以逗号或换行分隔。候选沿用对应引擎的接口地址和 API Key。主模型可以通过 subagent 的 models 操作查看候选，选择模型、思考强度或预算、system 提示词与 Prompt。

每批最多 4 个任务，同时运行 2 个。子代理共享项目与环境、使用独立上下文，不能继续创建子代理；主任务停止时会一起取消。单任务时限为 15–900 秒。

持久交互终端

使用 terminal 的 open 创建终端，保留返回的 terminal_id。exec 提交命令，read 继续查看输出，write 输入文本或快捷键。可以打开多个独立会话，每次返回近期历史。等待结束不会杀掉命令。

{"action":"write","terminal_id":"返回的终端ID","text":"yes","key":"enter"}
{"action":"write","terminal_id":"返回的终端ID","key":"c","modifiers":["ctrl"]}

终端跨工具调用和对话轮次保留状态。运行时重启后保留历史，旧进程不会恢复，输入不会重放。原命令工具 run_command 支持 1–3600 秒 timeout。

读取图片

{"path":"screenshots/home.png","intent":"检查按钮布局，并读出清晰可见的文字。"}

支持 PNG、JPEG、WEBP 与 GIF，每张最多 5 MiB。图片会发送给当前配置的供应商图片接口，需要所选模型支持视觉输入；当前免费接口不支持图片输入。

远端 Terminal MCP

Aster 支持通过项目的 .aster/mcp.json 配置 MCP 服务，并在模型设置中启用对应服务器名称。终端 MCP 使用稳定的对话标识保存会话，命令在远端服务器上执行。

{
  "mcpServers": {
    "terminal": {
      "type": "http",
      "url": "https://asteride.cn/terminal-mcp",
      "headers": {"Authorization": "Bearer YOUR_PRIVATE_TOKEN"},
      "conversationScoped": true
    }
  }
}

将 YOUR_PRIVATE_TOKEN 替换为服务管理员提供的访问凭据。访问凭据不会在官网公开提供。启用 conversationScoped 后，Aster 注入稳定的工作区与对话范围；子代理共享主任务范围。

服务提供 terminal_open、terminal_exec、terminal_write、terminal_read、terminal_list、terminal_resize 与 terminal_close。发送 Ctrl+C 可中断前台命令。wait_ms 仅决定等待多久，不会终止命令。
