完整使用指南 ↗
需要什么设备？＋

当前 APK 面向 Android 7.0 及以上的 ARM64 设备。首次使用需要准备运行环境；部分工具和模型请求需要联网。

可以使用自己的模型吗？＋

可以。在模型设置中填写对应引擎的接口地址、模型名称和 API Key。子代理候选模型沿用各引擎配置；实际可用能力取决于模型与供应商。

图片会发送到哪里？＋

图片读取会把文件发送到你当前配置的模型供应商视觉接口，每张最多 5 MiB。当前免费接口不支持图片输入。使用前请确认你愿意把该图片交给所选供应商处理。

它是 iPhone 应用吗？＋

Aster 当前是 Android 应用。页面中的手机边框用于展示你看到的真实 Android 界面，不表示提供 iOS 版本。
