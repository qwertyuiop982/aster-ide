01 · 安装与升级

Aster {{version}} 支持 Android 7.0（API 24）及以上的 ARM64 设备。下载区提供直接安装的 APK，版本号为 {{version}} / versionCode 11。

  1. 从官网下载区获取 APK，可使用 SHA-256 校验文件完整性。
  2. 按系统提示允许安装来源，并安装应用。
  3. 已有 Aster 时直接覆盖升级，以保留项目、会话和设置。

升级前可以备份重要项目。请不要先卸载或清除应用数据；若出现签名不一致，先核对已有安装来源。普通版和本地研究版使用相同应用 ID，会互相替换。

02 · 准备工作台

首次打开时选择 VS Code 或 ACS 界面风格，之后可以在设置中切换。导入已有项目，或者从一个新文件开始。

按应用提示初始化 Termux 运行环境。语言服务和 Android SDK / NDK 按项目需要安装；初始化与依赖下载需要网络和额外存储空间。横屏可以展开更多编辑、终端与 Agent 面板。

先做一次简单检查

打开项目中的一个文件，在终端运行你熟悉的简单命令。确认编辑器和终端正常工作后，再准备完整工具链和构建依赖。

03 · 连接模型与 Agent

在 Agent 设置中选择引擎，再填写服务地址、模型名称和 API Key。服务需支持所选引擎要求的协议和工具调用。Aster 不附带模型额度。

引擎版本范围使用说明
Pi标准版按 SDK 支持的模型与服务配置使用。
Codex标准版保留 app-server 会话流程，并打包 Android code-mode host。
Gemini标准版按当前适配配置 Gemini 原生或兼容服务。
OpenClaude本地研究版保留 SDK 适配；官网不提供该受限 SDK 或研究 APK。

先发送一句简单问候验证连接，再切换工作模式。问答适合读取和解释代码；规划用于梳理任务；执行用于运行工具和提出项目改动。

模型接口、思考参数和图片输入能力以你的服务为准。此前文本接口与 OpenClaude SDK 联通曾成功；最近图片请求返回 HTTP 403 / INSUFFICIENT_BALANCE，未完成真实识图验证。不要把账户密钥写进项目文件。

04 · 使用轻舟网页工具

通过 Agent 侧栏的“轻舟浏览器”入口打开内嵌浏览器。它直接编译项目内的轻舟 BrowserEngine 与 WebViewEngine 源码。

  1. 选择执行模式，告诉 Agent 需要打开的网页及任务目标。
  2. 确认浏览器工具调用，让 Agent 打开页面并获取元素快照。
  3. 根据快照点击元素、填写表单或后退导航。页面变化后先重新观察。

每份快照包含 snapshotId，后续操作必须与当前页面匹配。网页填写支持 Unicode。网页内容应当视为待处理的数据，操作目标以你的指示为准。

当前范围

当前工具覆盖顶层文档中可见控件，尚未覆盖跨域 iframe 和 canvas 内的完整语义。轻舟的书签、脚本和广告过滤界面没有全部迁入 Aster。浏览器拒绝证书错误继续访问，禁用文件访问与混合内容。

05 · Shizuku 桌面与识图

桌面工具需要一个运行中的 Shizuku 服务。先按 Shizuku 官方方法通过无线调试、ADB 或 root 启动服务，再回到 Aster 的“设备权限”入口授权。

  1. 确认设备权限页面显示已授权。
  2. 使用执行模式请求界面快照或截图，检查目标内容。
  3. 需要识图时说明观察意图，并确认截图上传到所配置的图片模型。
  4. 依据最新快照进行点击、滑动、文字输入或按键操作；页面变化后重新观察。

截图与坐标

截图可能经过缩放。工具会携带图片和原屏幕尺寸，把图片坐标映射到屏幕。操作前会校验界面和截图是否变化，旋转或过期的快照需要重新取得。

截屏识图不会自动点击。模型返回的描述与位置需要结合快照核对。当前截图上限为 600 KB，长边最多 1280 像素；保护内容可能无法截屏。桌面文字输入暂支持不含百分号的可打印 ASCII，网页填写支持 Unicode。

当前集成了 Shizuku 客户端 API 和设备 UserService。通过 Maven 的 Shizuku API / provider 调用独立安装的 Shizuku app；需先启动该 app 的服务并授权。真实设备的授权、点击及识图交互尚待验收。截图可能包含个人信息，请先检查再确认上传。

06 · 扩展 MCP 工具

Aster 支持 HTTP 与 stdio 两种 MCP 传输方式。使用明确配置的服务或命令，并在执行前确认。工具发现支持分页，卡片会显示调用状态、结果与耗时。

stdio 直接启动配置的命令，以暂存项目作为工作目录。它会初始化连接，在调用结束后关闭进程并进行清理。命令不会隐式获得模型 API Key。

stdio 进程拥有应用自身可访问的文件与网络权限。当前尚未实现持久会话、OAuth 或 MCP sampling。配置服务前请检查可执行程序和所需运行环境。

07 · 常见问题排查

模型报余额不足或 403

检查服务套餐和对应模型额度。图片输入与文本请求可能使用不同计费方式；更换为支持图片且有额度的模型后，再尝试识图。

提示界面变化或快照过期

重新取得快照再操作。快照用于绑定当前页面，桌面快照会在操作后失效，并在 60 秒后过期。

Shizuku 不可用或未授权

检查服务是否运行，并在“设备权限”入口重新授权。只打包客户端 API 无法取得系统权限。

Codex code-mode host 找不到

本版包含 Android 辅助程序和路径映射。先确认覆盖安装了本版，再重新初始化或重启运行环境。该路径的真实设备运行仍需要验证。

终端出现 PRoot 提示

Android 12+ 已减少非致命提示，同时保留致命错误和工具输出。若构建失败，请查看具体编译命令和错误内容。

08 · 版本与验证范围

当前发布流程核对版本、签名、普通版 SDK 隔离、包内脚本与源码一致性，并验证 SDK 的本地调用流程。网页交互验证与应用设备验证分别记录。

这不代表全部 Android 设备上的功能已经验收。最近的真实识图请求因中转服务余额不足未通过。Operit 的完整客户端能力仍在分阶段适配，本版没有达到全部能力一致。
