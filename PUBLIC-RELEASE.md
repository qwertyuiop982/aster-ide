# Aster 1.0.5 public source

This repository and the compact Release archive contain Aster's Android source, required upstream production source, native build recipes, agent runner sources/lockfiles, licenses and static website source. Restricted OpenClaude SDK material, credentials, signing keys, machine configuration, `.so` files, build intermediates, standalone test/example source trees and redundant upstream snapshots are excluded.

Use JDK 17, Gradle 8.13, Android SDK 35 / build-tools 35.0.0, NDK 29.0.14206865 and the native prerequisites in DEVELOPMENT.md. Set your SDK/NDK environment and run `./gradlew :app:assembleRelease`. Native binaries are generated under ignored `build/native/`; they are packaged in the APK, never the source archive. Sign your build with your own key.

Shizuku integration resolves `dev.rikka.shizuku:api:13.1.5` and `dev.rikka.shizuku:provider:13.1.5` through Maven. Aster calls the separate installed Shizuku application after the user starts and authorizes it. Neither Shizuku's server nor its API source tree is vendored. MIT notices remain in client APK assets. Qingzhou's BrowserEngine/WebViewEngine are compiled from retained source.

The two Codex native build recipes are `scripts/build_codex_agent.py` and `scripts/build_codex_host.py`. The Rust workspace is reduced to their normal/build dependency closure. Pi/Gemini sources and lockfiles remain available under vendor/ and research/; duplicate compressed snapshots were replaced by pinned download URLs and original hashes.

The production static website is generated by `website/v5/build.py --release-dir /path/to/release --output /path/to/site`; the builder verifies delivery.json against the signed APK before generating download metadata. Downloads use GitHub Release assets through gh-proxy.org. The older `website/build_release_site.py` is retained for the legacy multi-page site.

Retain upstream copyright/license notices. Root LICENSE preserves the inherited GPLv3 statement and exceptions; Qingzhou is AGPL-3.0, Operit is an LGPL-3.0 upstream reference, Shizuku API is MIT. Read THIRD_PARTY_NOTICES.md and client/SOURCES.json before redistributing. PUBLIC-RELEASE.json associates the built APK with this source delivery.
